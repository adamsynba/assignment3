# Healthy — Responsive Web Design Assignment #3

## Project topic
Healthy is a static sports and activities website that presents one membership for different workouts and partner locations.

## Project goal
Create a polished, responsive multi-page front-end website using HTML and CSS only. The site is designed for visitors who want to discover sports, compare membership options, find locations and test a booking form.

## Pages
- `index.html` — introduction, benefits and how the membership works
- `sports.html` — six activity categories, weekly schedule and activity story
- `services.html` — activity catalogue and pricing plans
- `locations.html` — six locations, booking demonstration form, process steps and FAQ
- `demo-result.html` — static form demonstration result page

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS media queries
- Native HTML form validation and `<details>/<summary>`

No JavaScript, Bootstrap or other CSS frameworks are used.

## Responsive testing
The project is designed and tested at 320px, 375px, 768px, 1024px and 1440px CSS viewport widths. The main breakpoints are 600px and 900px, chosen where the navigation, card grids and multi-column layouts need to change.

## Form limitation
The booking form is a static demonstration. It uses native HTML validation and navigates to `demo-result.html`; no information is sent or stored.

## Local opening
Open `index.html` directly in a browser or use Live Server in VS Code.
